# 죄수드라이브

차를 몰고 총 든 적들과 날아오는 탄환 사이를 뚫어 클리어 지점까지 달리는 게임이다. 목숨 시스템과 스테이지, 보스전이 들어 있다.

## 플레이 방법

Releases에서 받아 실행하면 된다.

방향키로 차를 움직이고 스페이스를 누르면 멈춘다. 적의 총알에 맞으면 목숨이 하나 줄고, 화면 오른쪽의 클리어 지점에 닿으면 다음 스테이지로 넘어간다. 스테이지는 네 개이고 중간에 보스전이 나온다.

남은 목숨은 화면 위에 아이콘으로 표시된다. 목숨을 다 잃으면 타이틀로 돌아간다.


## 구현 원리

목숨은 게임메이커에 내장된 `life` 값을 그대로 썼다. 각 스테이지 룸에 놓인 목숨 오브젝트가 룸에 들어올 때마다 `life` 를 5로 맞추고, 매 프레임 목숨이 남았는지 확인하다가 0이 되는 순간 타이틀로 보낸다. 화면 위의 목숨 아이콘은 `life` 값만큼 스프라이트를 반복해 그리는 내장 액션으로 표시한다.


## 소스와 배포본의 차이

`source/` 의 프로젝트 파일은 배포본을 만든 뒤 한 번 더 손본 판이다. 적을 잡거나 스테이지를 깰 때 점수가 쌓이고, 남은 목숨과 점수가 창 제목표시줄에 나오며, 목숨을 다 잃으면 하이스코어 표가 뜬다. 총알에 맞으면 차가 부서지는 것도 이 판에서 바뀐 점이다. Releases의 실행 파일은 당시 배포한 것을 그대로 두었다.
